# Retinal atlas modality figures

망막 영상 지도(`retinal-atlas-web`)의 영상 종류 페이지(`/imaging/<modality>/`)에 쓰는 실제 영상 예시다.
`projects/P003_ophthalmic_foundation_model_validation/code/build_atlas_modality_figures.py`가 `provider_figures/`의
공개 논문 그림(공급자 파일명 그대로, SHA-256 고정)에서 패널 하나씩 잘라 축소한다. 패널 글자와 저자의 화살표는 남겼다.
