# 망막 영상 측정 개념의 일반화 분류안

2026-11-20 · P003 프로젝트 공용 · 일반 지도 재설계를 위한 개념 초안

## 1. 목적과 권위

지도는 특정 실험에서 계산한 변수의 목록이 아니라, 망막 영상에서 무엇을 관측하고
어떤 속성을 측정할 수 있는지를 설명하는 일반 자료로 설계한다. 기존 190·178은
분류의 상한이나 개념 ID가 아니라 기존 구현과 출처를 연결하는 입력 자료다.

아래 체계는 문헌을 토대로 제안한 탐색·데이터 모델이다. 단일 국제 표준 ontology나
임상적으로 검증된 독립 개념의 확정 목록을 뜻하지 않는다. 참고한 지침의 범위와
개별 구현의 임상 타당성은 구분한다. 새 계측·학습·환자 분석은 수행하지 않았다.

## 2. 기본 구조: 대상 × 속성, 모달리티는 관측 조건

개념을 식별하는 기본 단위는 **측정 대상 × 측정 속성**으로 둔다. 해부학적 부위와
관측 신호의 의미가 바뀌면 하위 개념으로 구분한다. 모달리티·영역·통계량·방법·단위는
해당 개념의 구체적인 측정 명세를 완성한다.

```text
측정 대상: 망막 혈관
  측정 속성: 폭
    관측: 안저 사진의 가시 혈관 / OCTA의 검출된 flow-signal 혈관
    범위: 동맥·정맥, 유두 주변 구역, 대상 경로
    출력: 국소 폭, 평균·중앙값·분위수, CRAE·CRVE 등 정의된 요약
    명세: 해상도, 배율 보정, segmentation, 중심선, 산식, 단위
```

여기서 CRAE·CRVE는 임의 혈관 폭 평균의 다른 이름이 아니다. 혈관 선택 구역과 결합
산식이 있는 별도 측정 명세다. 안저 혈관 기하의 대표 항목과 실제 측정은
[SIVA 원 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC3440033/)를 참고한다.

일반 지도는 세 축을 교차해서 탐색하도록 한다.

| 축 | 질문 | 예 |
|---|---|---|
| 측정 대상 | 무엇의 속성인가? | 망막층, 혈관, 액체 공간, 드루젠, 유두, 영상 영역 |
| 측정 속성 | 무엇을 수치화하는가? | 두께, 면적, 부피, 폭, 구불거림, 연속성, 밝기 |
| 관측 모달리티 | 어떤 신호·표현에서 보는가? | 컬러 안저, structural OCT, OCTA, FAF, FA |

모달리티마다 독립적인 개념 목록을 중복 작성하기보다 공통 개념을 공유하고 관측
정의를 분리한다. 같은 모달리티 안에서도 서로 다른 target·slab·경계 정의는 보존한다.

## 3. 모달리티의 역할과 관측 한계

ASRS의 다중 영상 지침은 각 모달리티가 서로 다른 구조·혈관·광학 정보를 제공함을
설명한다. 이를 아래 탐색 축의 근거로 사용하며, 이 표 자체는 본 설계의 요약이다.
[ASRS 다중 영상 지침, 2024](https://pubmed.ncbi.nlm.nih.gov/38770073/)

| 모달리티 | 주 관측 정보 | 일반 지도의 핵심 측정 | 해석 경계 |
|---|---|---|---|
| 컬러 안저 사진·UWF | 2차원 투영 외관 | 가시 혈관 기하, 병변 존재·개수·투영 면적, 유두·황반 배치, 색·질감 | 일반 단일 사진으로 망막층 두께·병변 부피를 직접 계측하지 않는다. UWF 투영·배율을 명세한다. |
| Structural OCT | 깊이 방향 반사 신호와 단면·volume | 층 두께·부피·연속성, 액체·침착물·융기, 유리체–망막 경계 | 층 경계·스캔 간격·axial/lateral scale을 명세한다. 단면 면적과 3D 부피를 구분한다. |
| OCTA | 반복 OCT의 motion-contrast flow 신호 | slab별 flow-signal 점유율·길이 밀도, FAZ, flow deficit, 비정상 혈관망 | 일반 OCTA 밀도를 혈류 속도나 혈류량으로 부르지 않는다. 신호 소실을 곧바로 무관류 확정으로 바꾸지 않는다. |
| FAF | 자가형광 신호 | 저·고자가형광 영역의 면적·형태·패턴, 보정된 qAF | 일반 회색값과 qAF를 구분하며, 신호를 특정 물질의 농도로 바로 등치하지 않는다. |
| NIR·multicolor | 파장별 반사·흡수 대비 | 영역 반사 강도, 대비, 병변 경계·분포 | 컬러 사진의 RGB 강도와 같은 물리량으로 합치지 않는다. |
| FA·ICGA | 조영제의 시공간 신호 | 관류 영역, 누출·염색·pooling·충만의 관측 패턴과 시간 변화 | 누출과 OCT의 액체량, OCTA flow 신호는 서로 다른 관측량이다. |

1차 지도는 컬러 안저·OCT·OCTA를 중심으로 구성하고 FAF·NIR·FA·ICGA를 확장 축으로
포함한다. AO·초음파·분광/산소포화도 영상은 별도 획득 명세가 필요한 후속 확장이다.

## 4. 측정 대상별 1차 개념 목록

각 행은 탐색을 위한 대상군이며, 상세 개념은 그 아래 대상 × 속성으로 등록한다.
다음 표의 예시는 대표 후보이고 전체 항목 수를 닫아 두지 않는다.

| 대상군 | 일반적으로 정리할 측정 개념 | 주 관측 모달리티 |
|---|---|---|
| 해부학 기준 구조·배치 | 유두·컵·rim 크기와 형태, 유두–중심와 거리·각도, 중심와 pit의 폭·깊이·경사 | 안저, OCT; 실제 landmark와 단면 경계 필요 |
| 신경망막·망막층 | 총 망막·RNFL·GCL·IPL·ONL 등의 두께·부피·공간 분포, 층 경계 연속성·배열 | OCT |
| 광수용체·RPE·외망막 | EZ·ELM 등 band의 연속성·단절 범위, RPE 융기·분리·소실, 외망막 위축 범위 | OCT; 안저·FAF·NIR 관측과 대응 가능 |
| 맥락막·맥락막혈관 | 맥락막 두께·부피, 구조 OCT에서 정의한 혈관성/기질 영역 비율, OCTA choriocapillaris flow deficit | OCT, OCTA, ICGA; 구조와 flow 신호를 분리 |
| 망막 혈관망 | 폭·CRAE·CRVE·AVR, 길이·밀도, 구불거림·분지각, 연결성·분지·프랙탈 차원, 동정맥 관계 | 안저, OCTA, FA; 관측 혈관 집단과 방법에 의존 |
| 무혈관·저관류 관측 영역 | FAZ 면적·둘레·형태, 주변 flow-signal 점유, 관류 결손 영역의 면적·분포 | OCTA, FA; 신호 검출 한계·artifact 확인 |
| 국소 병변·액체·침착물 | 대상 존재·개수·크기·면적·부피·형태·높이·공간 분포 | 안저 병변과 OCT compartment를 각각 명시 |
| 유리체–망막 경계 | 접촉·유착 범위, traction 관련 형태, 망막전막·주름·박리·열공/원공의 경계와 크기 | OCT 중심; 안저·초음파 보완 |
| 영상 영역의 광학 외관 | 색·강도·반사·자가형광, 대비·질감·기울기·주파수·선 응답 | 해당 영상 모달리티; 조직 소견과 분리된 신호 측정 |

OCT band·경계 명칭은 [IN•OCT 용어 합의](https://pubmed.ncbi.nlm.nih.gov/24755005/)와
각 획득·분할 체계를 참조한다. APOSTEL은 quantitative OCT의 획득·분석·보고 명세를
정리하는 근거로 사용한다.
[APOSTEL 2.0](https://pubmed.ncbi.nlm.nih.gov/33910937/)

### 4.1 혈관 개념의 구체화

| 속성 | 정의할 출력 | 함께 기록할 조건 |
|---|---|---|
| 폭·구경 | 국소 직경, 평균·중앙값·분위수, 정의된 CRAE/CRVE/AVR | 동정맥 구분, ROI, 폭 정의, 요약 산식, 배율 |
| 면적 점유 | 혈관 또는 검출 flow-signal 면적 / 유효 ROI 면적 | 가시 큰 혈관인지 모세혈관 flow 신호인지, slab, threshold |
| 길이 밀도 | 중심선 길이 / 유효 ROI 면적 | 실제 길이와 골격 픽셀 개수의 차이, 대각선 가중, 단위 |
| 구불거림 | 정의된 경로 길이/chord 또는 곡률 기반 요약 | 경로 선택·분절·최소 길이·집계 가중치 |
| 방향·분지각 | 경로 접선 방향, 모혈관·딸혈관 사이 각도 | 실제 혈관 경로인지 밝기 기울기 방향인지, 기준 축 |
| 연결성·위상 | 연결 성분, 끝점, 분지, 루프, 연결 계층 | mask pixel·skeleton node·분지군의 정의, graph 생성법 |
| 공간 복잡도 | 프랙탈 차원 등 | box counting/다중프랙탈 등 방법, 척도 범위 |

OCTA에서 사용하는 density 명칭은 면적 기반과 길이 기반이 혼용될 수 있으므로
명칭보다 산식·분모·단위를 우선한다. 장비·slab·threshold 차이도 측정 명세에 포함한다.
[OCTA 영상 지침, 2020](https://pmc.ncbi.nlm.nih.gov/articles/PMC7708612/)

### 4.2 병변 개념은 대상과 속성을 분리

병변 명칭마다 존재·개수·면적·형태를 중복 정의하지 않고, 공통 연산을 공유하면서
실제 target과 관측상의 동등성은 따로 기록한다.

- 안저 target 예: 미세동맥류, 출혈, 경성 삼출물, 면화반, 드루젠, 색소 변화,
  위축, 신생혈관, 치료 흔적.
- OCT target 예: IRF 공간, SRF 공간, PED, 드루젠/침착물, SHRM, hyperreflective foci,
  망막/외망막 위축, 망막전막, 원공.
- 공통 속성: 존재, 개수, 크기 분포, 투영 면적·단면 면적·3D 부피, 높이, 둘레·형태,
  중심와까지 거리, 층/compartment, 군집·분포, 시간 변화.

예를 들어 안저 사진의 밝은 점과 OCT hyperreflective focus를 영상상의 유사성만으로
동일한 조직 병변으로 합치지 않는다. PED 전체를 단일 액체 종류로 취급하지 않는다.
2D mask 성분 수는 segmentation 연결 성분 수이며 임상 병변 개수와의 대응이 필요하다.

위축도 단순히 어두운 mask가 있다는 뜻으로 정의하지 않는다. 예를 들어 AMD 관련
cRORA는 여러 OCT 소견을 결합하는 임상 합의 정의가 있다. 개별 면적·band 소실 측정과
그 소견들을 조합한 판정 기준을 분리해 연결한다.
[Classification of Atrophy Report 3](https://pubmed.ncbi.nlm.nih.gov/29103793/)

### 4.3 광학 외관·질감의 위치

밝기·RGB·대비·GLCM·LBP·gradient·Haar·FFT·ridge는 일반적인 영상 측정으로 유지한다.
다만 해부학적 조직을 정확히 측정한다는 근거가 없는 경우 `영상 신호/패턴`으로
표시하고 혈관·RNFL·병변의 직접 측정 항목으로 격상하지 않는다.

일반 RGB 강도, OCT reflectivity, FAF intensity는 관측 신호가 다르다. 같은 ‘강도’
상위 속성을 공유해도 각각 다른 관측 명세를 갖는다. qAF는 내부 reference와 광학적
보정이 필요한 구체적 측정 방법으로 일반 FAF 회색값과 구분한다.
[qAF 원 방법 연구](https://pubmed.ncbi.nlm.nih.gov/22016060/)

## 5. 공통 측정 속성과 명세

| 속성군 | 대표 속성 |
|---|---|
| 존재·수량 | 존재 여부, 개수, 연결 성분 수, 수 밀도 |
| 크기·양 | 길이, 폭, 두께, 직경, 면적, 부피, 높이, 점유율 |
| 형태 | 둘레, 원형도, 편심도, 경계 불규칙성, 곡률, 구불거림 |
| 위치·배치 | 중심, 거리, 각도, 방향, 층/깊이, 상대 위치, 분포·군집 |
| 연결·복잡도 | 끝점, 분지, 연결 성분, 루프, 계층, 프랙탈 차원 |
| 연속·조직화 | band 보존、단절、결손、층 경계와 조직화 |
| 광학 신호 | 채널/파장별 강도, 반사·형광, 대비、질감、기울기、주파수 |
| 관류·조영 관측 | flow-signal 점유/결손, FAZ, 조영제 누출·충만의 시공간 특성 |

공간·시간·요약은 속성의 측정 명세다. 평균·중앙값·90백분위수는 같은 값이 아니지만
매번 별개의 임상 실체로 세지는 않는다. 추적 변화·변화율·양안 비대칭·영역 간 차이·비율은
부모 측정과 registration·시간 간격을 명시한 파생 개념으로 둔다.

구체적인 측정 정의에는 다음을 함께 기록한다.

1. 대상과 관측 표현: 해부학적 target, 병변/compartment, mask·surface·graph·signal.
2. 모달리티·획득: 장비·촬영/scan protocol·파장·해상도·스캔 크기·샘플링.
3. 공간 범위: 유효 FOV, 중심와/유두 기준, ETDRS 또는 명시된 ROI, 층·slab·축.
4. 계산 방법: 수동/자동 분할, 경계·threshold·그래프·집계 산식, 소프트웨어 버전.
5. 단위와 보정: px와 µm, px²와 mm², mm³, 비율, 배율·축장·투영 보정 여부.
6. 상태: 실제 0, 측정 불가, 미관측, 미수행을 구분하며 분모와 관측 가능 영역을 기록.
7. 비교 가능성: 같은 대상·관측·영역·단위·방법인지, 보정이나 변환이 검증됐는지.
8. 근거: 정의/용어 근거, 기술 정확도·반복성, 임상 연관성·효용을 각각 기록.

물리 보정 정보가 없으면 pixel 단위를 보존한다. 안저의 2D 투영 면적과 OCT 단면 면적·
volume을 같은 수치로 합치지 않는다. OCT 층 경계가 다르면 같은 ‘두께’라는 이름만으로
값을 교환하지 않는다. 이는 [OCT 장비 간 비교 원 연구](https://pubmed.ncbi.nlm.nih.gov/25058482/)
와 APOSTEL에서 다루는 명세 문제를 본 지도의 비교 규칙으로 구체화한 것이다.

## 6. 190·178을 일반 체계에 연결하는 방법

### 6.1 목록의 위치

- 178개는 모두 안저 입력에서 파생한 특징 목록이다. A59·V19·L64·R36은 구현 계열이다.
  독립 임상 소견 178종이나 안저 분야 전체 개념을 포괄하는 목록은 아니다.
- 190개는 안저139·OCT25·범용mask13·분할검증6·임상기록7로 구성된 초기 계산 목록이다.
- OCT25는 제한된 label-mask 표현형이며 일반적인 OCT 전체 계측 목록이 아니다.
- 현재 62개 묶음도 그 입력 목록에서 만든 탐색 분류다. 일반 지도의 최종 범위를
  기존 62개에 고정하지 않는다.

### 6.2 기존 항목의 새 위치

| 기존 항목/계열 | 일반 지도에서의 위치 | 통합 시 보존할 구별 |
|---|---|---|
| RGB 평균·분포·밝기·대비 | 영상 영역 × 광학 신호 속성 | 채널, 스케일, 보정, ROI |
| GLCM·LBP·Haar·FFT·fine RMS·ridge | 영상 영역 × 질감/주파수/선 응답 | 알고리즘·파장·척도; 해부학적 실체로 등치하지 않음 |
| 영상 gradient cos2/sin2 | 영상 신호 × 변화 방향 | 혈관 graph 진행 방향과 구별 |
| vessel fraction·length·width·tortuosity | 혈관망 × 면적/길이/폭/형태 | 혈관 mask, 중심선, 분모, 경로·단위 |
| A의 Sato 근사선 | 영상 근사선 × 양·형태·방향 | 혈관 밀도와는 proxy 관계, 동일 개념의 검증된 구현이 아님 |
| V19 | 혈관 graph × 기하·위상 | pixel graph와 실제 혈관 해부학의 대응 미확정 |
| L64 | 국소 ROI × 밀도·대비·기울기 방향 | 16개 위치 × 4측정값; 위치를 임상 개념 16종으로 늘리지 않음 |
| R36 | 국소 영상 × 다중척도 ridge 응답 | 위치·척도·극성; RNFL/광반사 측정으로 확정하지 않음 |
| weighted-centroid 관계 | 영상 신호 가중 중심 × 공간 관계 | 실제 유두/중심와 landmark 거리와 구별 |
| OCT IRF/SRF/PED/SHRM mask | 해당 target × 존재·면적·성분·분포 | target별 관측·단면/volume 구분 |
| legacy IS/OS label | 원 label target × 보존·단절 | 현대 EZ 명칭으로 자동 치환하지 않고 원 label 정의부터 확인 |
| generic mask morphology | target 미지정 공통 측정 연산 | target이 정해져야 임상적 측정 개념으로 연결 가능 |
| 4개 측정 곱 | 부모가 명시된 파생 조합 | 새로운 해부학적 실체로 세지 않음 |
| FOV·분할 실패·선명도 등 | 획득·측정 품질/QC | 영상 신호와 QC 역할은 복수 태그 가능 |
| Dice/IoU 등 6개 | 측정 방법의 검증 | 환자의 망막 표현형 목록과 분리 |
| 시력·안압·기록 두께 7개 | 연결된 임상 기록 | 기록 두께 추출을 OCT 영상 두께 계산으로 바꾸지 않음 |
| AI 점수·질병/병변 확률·불확실성 | 모델 출력 | 해부학 측정과 분리; 모델 분할을 사용한 기하 측정과도 구분 |

기존 전체 368개 등록을 유지하되, 관계를 `정의가 같은 구현`, `같은 속성의 다른 명세`,
`proxy`, `derived_from`, `검증/QC`, `연결 임상 기록`, `모델 출력`으로 기록한다.
현재 단계에서 산식 수준 동등성이나 중복 제거 후 고유 개념 수를 새로 확정하지 않는다.

### 6.3 현재 목록 밖에서 추가해야 하는 대표 영역

망막층의 직접 OCT 두께·부피, 유두·컵·rim의 실제 구조, 맥락막 구조, EZ/ELM/RPE의
명확한 관측 정의, FAZ·slab별 OCTA 계측, 조영 관측, FAF/qAF, 입체 병변 부피와
종적 변화가 대표적인 확장 영역이다. **개념을 수록했다는 사실과 계산 구현이 있다는
사실은 별개**이므로 정의 수록·구현 가용·기술 검증·임상 근거를 따로 표시해야 한다.

## 7. 웹 지도 재설계 방향

첫 화면은 `망막 영상 측정 개념 지도`로 구성하고 대상군·측정 속성·모달리티로 탐색한다.
190·178, 실험 ID, 성능·우선순위는 주 탐색의 제목·통계 카드에서 내린다. 출처와 구현의
상세 정보로 연결하며 종전 지도는 출처 자료로 보존한다.

개념 상세의 순서는 정의 → 관측 가능한 모달리티 → 대표 측정 명세·단위 → 실제 출력의
의미와 한계 → 구현 → 기술·임상 근거 → 관련 개념·질병 맥락으로 둔다. 질병은 보조
탐색 축이고 동일 질병에 연결됐다는 이유로 두 측정값을 같은 개념으로 합치지 않는다.

페이지의 분류 화면은 다음처럼 나눈다.

- 측정 개념: 조직·혈관·병변·영상 신호의 대상 × 속성.
- 측정 방법: 입력·ROI·단위·알고리즘·비교 조건.
- 품질·검증: 관측 가능성, artifact, 반복성, segmentation agreement.
- 연결 자료: 임상 기록·모델 출력·기존 구현/출처.

기존 T1–T4는 이 일반 분류의 기본 계층으로 사용하지 않는다. 정의의 성격,
측정 오차, 임상 타당성과 모델 의존성은 별도의 속성으로 다룬다.

본 단계의 산출물은 일반화 분류안과 기존 목록의 연결 원칙이다. 웹 화면 개편 및
개별 항목의 새 schema 매핑은 이 정의를 기준으로 수행하는 후속 구현 단계다.
