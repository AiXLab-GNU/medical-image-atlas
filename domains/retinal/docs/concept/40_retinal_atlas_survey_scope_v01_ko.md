# 망막 영상 지도 조사 범위와 목록 설계

2026-11-20 · P003 프로젝트 공통 · **확정 범위**(2026-11-20 사용자 승인, 권장안 반영)

## 1. 진행 원칙

- 먼저 망막 영상의 해부 구조와 병변·소견을 정리한다.
- 영상 종류 → 해부 구조·병변 → 정성적 특징·정량적 측정 → 관련 질병 순서로 정리한다.
- 그동안 모은 정량 측정 자료를 원 출처와 함께 연결한다.
- 질병 진단 AI·알고리즘의 연결과 분석은 후속으로 미룬다.
- 이번 조사는 정의·관측·측정·질병 관계의 정리이며, 웹 구현·영상 수집·새 계산은 하지 않는다.

## 3. 목록 구성

| 목록 | 정리할 대상 | 항목별로 기록할 내용 |
| --- | --- | --- |
| A. 영상 종류·표현 | 촬영 방법과 그 안의 영상 표현(뷰·slab) | 한영 명칭, 신호·구조, 2D/3D, 관측 한계, 수록 수준 |
| B. 해부 구조 | 위치 기준·구역, 큰 구조, 층·경계, 혈관망 | 한영 명칭, 쉬운 정의, 상위 구조, 위치, 영상별 관측 |
| C. 병변·소견 | 영상에서 관찰되는 비정상 요소와 변화 | 한영 명칭, 정의, 병변군, 발생 구조·깊이, 영상별 관측, 구별할 소견 |
| D. 특징·측정 | B·C의 정성적 특징과 정량적 속성 | 대상, 속성, 정성/정량, 영상, 구역·경계, 단위, 필요 조건 |
| E. 관련 질병 | C·D가 진단·분류·관찰에 쓰이는 질병 | 질병, 관련 소견·측정, 관계 유형, 분류 체계·판본, 근거 |
| F. 기존 측정 대응 | 기존 등록표·패키지·실험의 측정 항목 | 원 ID·출처·정의·입력·단위, D와의 관계 유형 |

모든 목록은 공통 ID로 연결한다. 영상별·질병별로 같은 요소의 정의를 반복 작성하지 않는다.

### 3.1 A의 두 단계

같은 영상 종류도 표현에 따라 볼 수 있는 구조와 측정이 다르다. A는 `영상 종류 → 영상 표현`
두 단계로 둔다. 예: 구조 OCT → B-scan·volume·en-face·유두 원형 스캔,
OCTA → 표층·심층·외망막·맥락막모세혈관 slab. B·C의 관측 가능성은 가능한 한 표현 단위로 적는다.

### 3.2 D–F 관계 유형

F의 각 항목은 D에 다음 중 하나로 연결한다([일반화 분류안 §6.2](10_retinal_image_measurement_concept_taxonomy_v01_ko.md)).

| 관계 | 뜻 |
| --- | --- |
| `same_definition` | 같은 대상·속성·관측·산식 |
| `variant_specification` | 같은 속성의 다른 구역·산식·단위·영상 |
| `proxy` | 다른 관측량으로 근사 |
| `derived` | 다른 측정에서 계산된 파생 값 |
| `qc_validation` | 획득·측정 품질 또는 분할 검증 |
| `clinical_record` | 영상이 아닌 임상 기록 |
| `model_output` | AI 모델의 출력 |
| `image_signal` | 해부·병변이 아닌 영상 신호·질감 |
| `unmapped` | 대응 미확인 |

mask 연결성분 수는 임상 병변 개수가 아니고, FOV 비율로 정규화한 값은 사분면별 개수가 아니다.
이런 차이는 `variant_specification` 또는 `proxy`로 기록하고 같은 측정으로 합치지 않는다.

### 3.3 E의 관계 유형과 판본

| 관계 | 뜻 |
| --- | --- |
| `diagnostic_criterion` | 진단 기준을 구성 |
| `severity_classification` | 중증도·병기 분류를 구성 |
| `activity_monitoring` | 활동성·경과·치료 반응 관찰 |
| `prognostic` | 예후와 연관 |
| `characteristic_nonspecific` | 흔히 동반되지만 단독으로 특이하지 않음 |

분류 체계를 근거로 쓸 때는 이름과 판본(발행 연도·기관)을 적고, 조건이 있으면 함께 적는다
(예: ICDR에서 미세동맥류만 있을 때 경도 NPDR). 소견 하나와 질병 하나의 단순 대응표로 쓰지 않는다.

## 4. 1차 조사 범위

### A. 영상

| 수준 | 영상 |
| --- | --- |
| 상세 수록 | 컬러 안저·광각/초광각 안저, 구조 OCT, OCTA |
| 관측 가능성과 대표 소견만 | FAF, NIR·멀티컬러, FA, ICGA |
| 제외(후속) | 적응광학, 초음파, 분광·산소포화도·기능 영상 |

### B. 해부 구조

위치 기준·구역 체계, 후극부·황반·중심와·주변부, 망막층·band·경계(IN•OCT 명칭),
광수용체·RPE·브루크막, 망막 혈관·모세혈관망·FAZ, 맥락막과 혈관층, 유리체–망막 경계,
시신경유두·컵·신경망막 테·유두주위 구조.

### C. 병변·소견

혈관성 병변·출혈·관류 소견, 삼출·침착, 액체 공간·부종·박리·융기, 반사 소견과 층 배열,
색소·RPE·외망막 변화와 위축 구성 소견, 유리체–망막 경계, 주변부 변성·열공·망막박리,
시신경유두 소견, 반흔·치료 흔적. 희귀 병변 전수 수록은 1차 완료 조건에 넣지 않는다.

### D. 특징·측정

정성: 존재·종류, 위치·깊이, 형태·경계, 색·반사/형광, 배열·연속성, 분포, 시간 변화.
정량: 개수, 길이·폭·두께·높이, 면적·부피·점유율, 형태, 거리·각도·분포, 연결성·복잡도,
신호 통계, 변화량.

## 5. 상세 깊이

- **1단계:** 모든 항목에 정의, 관측 영상, 대표 측정(무엇을 어떤 영상에서 재는가)을 채운다.
- **2단계:** F와 연결되는 항목부터 측정식·구역·경계·단위·획득 조건을 상세 수록한다.

## 6. 산출물과 완료 기준

| 산출물 | 위치 |
| --- | --- |
| 원본 표 데이터(A–F, 출처) | `docs/surveys/retinal_atlas_catalog/` CSV |
| 통합 읽기 문서 | 표 데이터에서 만든 Markdown |
| 미조사·미확인·정의 충돌·영상 미확보 목록 | 표 데이터의 상태 열과 통합 문서의 별도 절 |

원본은 표 데이터다. 통합 문서는 표에서 읽기용으로 만들며, 손으로 고친 내용이 표와 어긋나지
않게 한다. 웹앱 데이터는 이후 이 표에서 변환한다.

**1차 완료 기준:** 1차 상세 영상 3종의 주요 구조·병변 전부에 정의·관측 영상·대표 측정이
채워지고, 1차 질병마다 관계 유형과 분류 체계 판본이 붙으며, F 출처의 전 항목이 D에 대응되거나
`unmapped`로 표시된다.

## 7. 검증 상태와 의미 검사 (2026-11-20 보완)

외부 검토에서 1차 결과가 "범위가 넓은 목록 초안"이라는 지적을 받아 다음 규칙을 추가했다.

- **F 대응은 미검토 후보다.** 미대응 0건은 의미상 대응 완료가 아니며, 같은 정의로 확정한 대응도 아직 0건이다.
  생성기는 F 대상과 D 대상의 일치(교차는 `proxy`만 허용)와 출력 형태의 호환을 검사한다.
- **특징 적용 관계를 명시한다.** 공통 특징은 형태·측정 분류별 세트와 대상별 지정으로 적용하며, 모든 B·C 항목은
  직접·공통 적용·해당 없음·미조사 중 하나의 상태를 갖는다.
- **검토 상태를 구분한다.** 서지 연결, 정의 확인(초록·원문), 측정법 확인, 전문가 검토를 구분하고,
  분류 출처와 일반 근거 출처를 따로 기록한다. 근거가 없는 질병 관계는 `needs_source`로 둔다.
- **관측 신호와 해석을 분리한다.** 영상 종류 단위의 관측 표시는 신호 가용성만 뜻하며, 표현 단위의 직접 신호와
  해석 조건은 관측 표에 기록한다.
- **원본 식별자를 보존한다.** F는 원본 측정 ID·개념 ID·정의 해시·구역·통계량·파생 관계를 함께 옮긴다.

2단계(측정식·구역·단위 상세화)는 정의·연결이 검토된 항목부터 진행한다.
