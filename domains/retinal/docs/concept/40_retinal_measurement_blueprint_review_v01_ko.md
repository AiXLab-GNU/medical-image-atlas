# 망막 정량 지도 청사진·샘플 검토

2026-11-20 · P003 프로젝트 공용

## 현재 범위

사용자 요청에 따라 전체 수록을 보류하고, 일반화된 분류 청사진과 소수 샘플을 먼저
검토한다. [독립 다중 페이지 앱](../../packages/retinal-atlas-web/README.md)이 전용 8877 사이트를
제공한다. 이전 [단일 HTML](../history/retinal_measurement_blueprint_v01_ko.html)은 역사 자료다. 정량지표 전수 통합·질병 전수 수록·모든 개념의 영상 확보를 완료한 것으로
표시하지 않는다. 기존 190·178은 청사진에서 구현 출처라는 관계를 설명하며 전수 이관은 보류한다.

## 샘플과 표시

네 원문 그림만 사용한다: 정상 망막층, 맥락막, OCT 병변, 위축의 안저/FAF/OCT 비교.
모두 실제 영상이 포함된 공개 그림이며 원본은 중앙 resources에 한 번 보존한다.
영상·표식의 출처와 라이선스는 화면에 표시하고 `source_manifest.json`에 기록한다.

각 샘플은 어느 부위를 어떤 방향·방법으로 보는 이미지인지 설명하고 가장 높은 수준의
해부 구조를 쉬운 말로 정의한다. 기본 OCT는 망막·색소상피·맥락막 세 구조부터 보인다.
`세부 망막층`을 선택하면 RNFL·GCL·IPL·INL·OPL·ELM·EZ·RPE·맥락막을 서로 다른
색·번호·한글 범례로 연결한다. 원문 화살표 끝을 따라 위치 안내용 SVG 점을 추가하며
색상 켜기/끄기를 지원한다. 이는 영역 전체를 추적한 segmentation이나 두께 측정 결과가 아니다.
ONL 등 모든 층을 수록한 것으로 표시하지 않는다. 원본 확대는 원문 그림 그대로다.

병변은 해부 구조 설명과 다른 영역에 둔다. 낭성 공간·층간분리·견인성/장액성 박리·
EZ 단절·DRIL·경성 삼출물은 개별 버튼으로 분리하고 해당 원문 패널을 금색 테두리로
강조한다. 위축 비교에서도 사례 패널만 별도로 선택한다. 패널 테두리는 병변의
픽셀 경계를 추적한 분할이 아님을 명시한다. 전문 측정 조건은 펼침 영역으로 둔다.

## 설계 선택과 운영

대상 × 속성 × 모달리티를 중심으로 구조·혈관·병변·신호의 대상군을 배치한다.
자료가 없는 영역은 `설계만`으로 표시한다. 샘플 상세는 실제 영상, 볼 위치,
연결할 측정 개념, 필요한 조건, 해석 범위, 출처 순서다. 수집·조사 범위를 더 늘리는
대신 이 양식과 계층 색상·원본 확대를 먼저 평가한다.

서비스는 `packages/retinal-atlas-web/`의 Flask/Waitress 앱, localhost 8877을 사용한다.
홈·청사진·해부 구조·병변·샘플은 개별 URL과 서버 렌더링 HTML을 가진다.
이미지 네 개는 명시적 allowlist로 제공하며 resource 디렉터리나 manifest는 노출하지 않는다.
이전 실험 종속 HTML은 원래 문서·artifact 위치에 보존한다. 현재 운영은
[다중 페이지 설계·운영 기록](40_retinal_atlas_web_architecture_v01_ko.md)을 따른다.

## 평가 후 다음 단계

1. 분류 이름과 대상·속성·관측 방법의 관계를 평가한다.
2. 계층 색상, 한글 범례, 원본 및 패널 안내가 명확한지 평가한다.
3. 같은 상세 양식이 해부학·병변·다중 영상 비교에 맞는지 평가한다.
4. 수정 방향이 정해진 뒤 개념·병변·영상 및 구현 대응을 순차 확장한다.

  HEAD/GET, 미등록 경로·resources manifest·포털 API 차단을 확인했다.
- 네 원본 그림의 image format·SHA-256과 상대 resource view를 확인했다.
- Chromium에서 네 이미지 로딩, 세 개 큰 구조와 아홉 세부 색상 전환, 원본 토글,
  기본 해부 설명, 별도 병변 패널 강조·해제, 원본 dialog·Escape·너비맞춤,
  hash 직접 접속, 출처 링크 및 390px 모바일 표시를 확인했다. JS 오류 0건이다.
- 전역 명명 감사에는 기존 `studies/laterality/docs/manuscript/outline.md` 위반 1건이
  남고 새 경로 위반은 없다. 기존 구조 기대값 검사 실패는 이전 운영 문서의 기록을
  유지하며 본 샘플 작업과 섞어 수정하지 않는다.
