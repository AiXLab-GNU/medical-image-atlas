# 망막 측정 알고리즘 서베이와 패키지화 v01

- 상태: 구축 단계 정리안(문헌 대조·전문가 검토 전)
- 대상: 망막 영상 지도의 측정 목록(`retinal_atlas_catalog/d_features_v01.csv`, `feature_role = measurement` 160개)
- 구현: [`packages/retinal-measures/`](../../packages/retinal-measures/README.md)
- 작성일: 2026-11-20

## 1. 목적과 범위

측정 목록의 각 항목에 대해 "이미 알려진 계산 방법"을 모으고, 분할 결과(mask·OCT 경계면·위치점)나 원영상을 넣으면
값이 나오는 함수로 묶었다. 이 문서와 패키지는 다음을 하지 않는다.

- 분할 자체: 병변·혈관·층 분할 모델은 입력을 만드는 별도 단계다. 패키지는 분할 결과를 받는다.
- 판정: 등급·범주 기준과 임계값은 질병 페이지의 몫이다. 함수는 측정값만 돌려준다.
- 검증: 아래 참고문헌은 기억에 기반한 방법 출처 표기이며 원문 대조 전이다(`reference` 필드도 같다).

근사만 있던 103개를 새 단계 "측정 함수 있음"으로 표시한다. 이 단계는 입력을 만드는 분할이 연결되지 않았다는 뜻이다.

## 3. 공통 규약

- 반환형 `Measurement(feature_id, value, unit, status, note, detail)`.
  `status`는 `ok`, `not_observed`(평가했으나 없음), `not_evaluable`(입력 부족)이며 결측을 0으로 바꾸지 않는다.
- 보정 `Spacing(x_mm, y_mm, z_um)`. 보정이 없으면 px 단위로 돌려준다.
- 방향: 안저 사분면은 중심와–유두 축 기준(비측 = 유두 쪽), OD/OS를 인자로 받는다. ETDRS·TSNIT도 같다.
- 모든 함수는 `feature_id`를 인자로 받아 같은 계산을 병변별 측정에 재사용한다(예: 면적 → 경성삼출물·출혈·NVD 면적).

## 5. 함수가 없는 14개

판독자가 영상을 보고 기술하는 정성 범주이거나 다른 검사(형광 누출)의 동적 해석이 필요한 것들이다. 이 항목들은 AI 분류
출력이나 판독 기록으로 붙이는 것이 맞다(`retinal_ai_feature_use` study의 연결 대상).

유두 경계 선명도, 유두 색, 중심와 반사, 신경섬유 줄무늬, 자가형광 양상, 위축 가장자리 자가형광 양상, 출혈 깊이,
유리체 출혈 가림 정도, 신생혈관 누출, 삼출물 배열, SDD 단계, MNV 활동성 징후, 망막전막 견인 징후, 소견 정도(공통).

## 6. 입력 공백과 다음 연결

패키지는 계산 단계까지다. 실제 영상에서 값을 내려면 입력을 만드는 분할이 필요하며, 지금 연결 가능한 것과 빈 것은 다음과 같다.

| 입력 | 지금 쓸 수 있는 것 | 비어 있는 것 |
|---|---|---|
| 안저 병변 mask | IDRiD·FGADR 전문가 mask(공개 데이터) | 자동 분할 모델 연결 |
| 혈관·동정맥 mask | Refined IDRiD 혈관 mask, 프로젝트 혈관 분할 | 동정맥 구분 |
| 유두·컵 mask | IDRiD 유두 mask | 컵 mask |
| OCT 경계면·병변 mask | AMD-SD 병변 mask | 층 경계면 분할 |
| OCTA 슬랩 | — | 데이터·슬랩 생성 |

IDRiD 학습 세트 3장에서 미세동맥류 개수, 출혈 개수, 경성삼출물 면적, 분포 양상, 유두 면적과 장단축비를 계산해
동작을 확인했다(값은 `/tmp` 점검 출력, 저장 산출물 아님). 이는 실행 확인이며 정확도 평가가 아니다.

## 7. 서비스 연결

- 빌더 `code/build_retinal_atlas_catalog.py`가 registry를 읽어 `atlas.json`의 `impl.package`(함수·입력·방법·참고)를 채우고,
  registry가 표에 없는 feature를 가리키면 빌드를 멈춘다.
- 측정 목록 페이지는 패키지 함수 수와 행별 함수명·입력을, 항목 페이지는 측정 행마다 함수·입력·방법을 보여 준다.
