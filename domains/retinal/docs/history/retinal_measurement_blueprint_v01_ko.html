    측정으로 이어지는가

    무엇을 어떤 조건에서 측정하는지, 무엇까지 해석할 수 있는지가 상세 화면에서 드러나는지 확인합니다.

    현재: 청사진 + 소수 샘플다음: 분류·표시 방식 평가와 수정이후: 개념·병변·구현별 자료 확장
    기존 구현 자료와 분류 원칙

    기존 190·178개는 구현 출처로 연결할 자료입니다. 전체 개념 수나 분류의 기준으로 사용하지 않습니다. 측정 품질·검증, 임상 기록과 모델 출력은 영상 개념과 구분합니다.

    기존 자료 탐색기존 구현 항목 대응

    설계 검토용 샘플 · 원문 그림의 사진과 기존 표식은 그대로 유지했습니다. 추가 계층 색상은 설명용 위치 안내이며 전문가 확정 분할이 아닙니다. 각 이미지의 사용 조건은 원문 라이선스를 따릅니다.
