그림과 추가 표식

원문 전체 그림을 유지하고, 별도의 색상 점·번호 또는 금색 패널 테두리를 겹쳐 표시합니다. 원본 확대에서는 추가 표식 없이 원문을 봅니다. 추가 표식은 설명용이며 분할이나 새로운 계측 결과가 아닙니다.

정상 망막층(다른 예, Yorston 2025)만 CC BY-NC-SA 4.0 예외 그림입니다. 상업적으로 쓸 수 없고 고쳐 만든 것도 같은 조건이어야 하므로, 서비스 표시를 겹치지 않고 원문 그대로 싣습니다. 나머지 네 그림은 CC BY 4.0입니다. 예외 목록은 저장소의 LICENSE-docs.md에 있습니다.
